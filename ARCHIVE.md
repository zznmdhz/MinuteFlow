# Binary release archive

This branch documents historical MinuteFlow releases for which only the
original macOS installation packages were recovered.

- `v0.9.0`: archived ZIP and DMG are available in the GitHub Release.
- `v0.10.0`: archived ZIP and DMG are available in the GitHub Release.

The tagged commits are deliberately empty archival markers. No corresponding
verifiable source snapshots were found, so this repository does not present
older or newer source code as if it were the source for those versions.
