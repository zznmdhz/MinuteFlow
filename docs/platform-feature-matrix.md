## 发布时必须填写的结果

- 产品版本、Git commit、Mac/Windows 文件名、SHA256、构建运行记录。
- 自动化检查数量与涵盖范围；失败/未实现/待实机项逐项列出。
- Windows 实机型号/系统版本/音频设备、实际测试时长与权限/凭据检查。
- 发布渠道：未满足音频、凭据与完整功能门禁时使用 preview；不能称“完整稳定版”或“100%没有问题”。
- 平台差异：真实音频格式、定位、签名、架构支持等，不隐藏差异。源代码/构建产物完成与硬件验收完成分别说明。
